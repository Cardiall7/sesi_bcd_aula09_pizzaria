# Sistema de Banco de Dados - Pizzaria (sesi_bcd_aula09_pizzaria)

Repositório criado para a atividade prática da aula de Banco de Dados, focando em manipulação de dados (DML), criação de consultas avançadas com agrupamentos (`GROUP BY`, `SUM`, `COUNT`) e criação de visões (`VIEWS`).

## 🛠️ Atividades Realizadas

1. **Criação de Views (`views.sql`):**
   - Relatório geral relacionando pedidos, itens, clientes e pizzas com o cálculo do subtotal por item.
   - Visão agrupada calculando o valor total de cada pedido.
   - Visão agrupada contando a quantidade total de pizzas por pedido.

2. **Manipulação de Dados e Consultas (`queries.sql`):**
   - Inserção de novo cliente, telefone e registro de seu pedido inicial.
   - Inserção de uma nova pizza no cardápio ("A moda do chef").
   - Registro e posterior alteração/atualização de itens solicitados por cliente.

## Estrutura do Repositório
- `schema.sql`: Script de criação das tabelas do banco de dados.
- `queries.sql`: Comandos DML (inserções, atualizações e exclusões solicitadas).
- `views.sql`: Definição das views analíticas.
